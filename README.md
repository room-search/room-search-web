# 룸서치 · Room Search

방탈출 테마를 지역, 난이도, 공포도, 가격, 플레이 시간으로 빠르게 찾아보고 기기에 찜해 두는 반응형 웹 앱입니다. 로그인 없이 사용할 수 있습니다.

## 시작하기

필요한 버전은 Node.js 20.19 이상입니다.

```sh
npm install
cp .env.example .env.local
```

`.env.local`의 `ROOM_SEARCH_API_KEY`에 API 키를 입력하고 개발 서버를 실행합니다.

```sh
npm run dev
```

개발 서버는 기본적으로 `http://localhost:4173`에서 실행됩니다. 포트는 `PORT` 환경 변수로 바꿀 수 있습니다.

## 빌드 및 운영

```sh
npm test
npm run build
npm start
```

운영 환경에서도 Node.js 서버를 실행하고 `ROOM_SEARCH_API_KEY`를 비밀 환경 변수로 설정해야 합니다. 정적 파일만 제공하는 GitHub Pages에서는 API 키를 안전하게 보관할 수 없으므로 이 서버를 함께 실행할 수 있는 호스팅이 필요합니다. 빌드 결과는 `dist/`에 생성됩니다.

API 키는 브라우저 코드에 포함하지 않습니다. Node 서버가 `X-API-Key` 헤더를 붙여 APISis API를 호출하며, 검색 결과와 지역 목록은 짧게 캐시합니다. 사용자 찜 목록과 테마 모드는 각 기기의 `localStorage`에만 저장됩니다.

## 제공 기능

- 테마명 검색, 정렬, 지역 빠른 선택과 상세 지역 필터
- 난이도, 공포도, 가격, 플레이 시간, 운영 상태 필터
- 브라우저에 저장되는 찜 목록
- 테마 상세 정보, 카페 주소·예약 링크·전화 연결, 공유 링크
- 다크 모드, 키보드 검색 단축키, 모바일 필터 시트
- 휴대폰·태블릿·데스크톱 화면에 맞춘 반응형 레이아웃
